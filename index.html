Veil-PKG Repository

Custom Arch Linux binary repository by TheHolyVeil.

Quick Setup

Add the following lines to the bottom of your /etc/pacman.conf:

[Veil-PKG]
SigLevel = Optional TrustAll
Server = https://theholyveil.github.io/Veil-PKG/

Then sync and refresh your package databases:

sudo pacman -Syy

Hosted Packages

machina x86_64

Machina Rust File Manager binary.

sudo pacman -S machina

glasspad x86_64

GlassPad Tauri Desktop Application (provides scratchpad binary).

sudo pacman -S glasspad

yay-bin x86_64

Pre-compiled AUR Helper for quick installation without chroot compilation overhead.

sudo pacman -S yay-bin
